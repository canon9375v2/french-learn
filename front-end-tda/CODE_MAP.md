# Code Map — Frontend TDA

## Start here

- `src/App.tsx` — main dashboard and API integration
- `src/App.css` — dashboard styling
- `src/index.css` — global reset and theme tokens

## Main responsibilities

### `App.tsx`
- check backend health
- load params
- load sessions
- show analysis result
- save session data and strategy params

### `App.css`
- layout, cards, tables, forms, sliders, status styles

### `index.css`
- global variable definitions and app reset
